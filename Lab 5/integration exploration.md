2. LED Traffic Light Module 

### Code location 
Code for the integrated circuit can be found in the main.cpp file under src in Lab 5

### Cicuit Functionality
The circuit acts as an alert to the user. If any object gets closer than 50 cm to the sensor it will go from green to yellow on the traffic light module. If it is less than 20 cm to the sensor it will go to red. Changing the distance allows the different colors to transisiton.
